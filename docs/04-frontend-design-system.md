# 04 — Frontend Design System, Atomic UI, Theming & i18n

## 1. Tech Stack & Libraries

- **Framework**: SvelteKit (`@sveltejs/adapter-static`, SPA mode) + TypeScript (`strict: true`)
- **Styling**: Tailwind CSS v4
- **Headless Primitives**: `bits-ui` (accessible dialogs, selects, switches, tooltips, dropdowns)
- **Icons**: `lucide-svelte` (single consistent icon family across the entire app)
- **i18n**: `@inlang/paraglide-js` (compile-time, type-safe message functions)

## 2. Atomic Design Architecture (`frontend/src/lib/components/ui/`)

**Strict Rule — Reuse before Create**:
Before building any UI element, inspect `src/lib/components/ui/`. Never duplicate buttons, inputs, badges, modals, or cards in route files.

```text
frontend/src/lib/components/ui/
├── atoms/
│   ├── Button.svelte           # Variants: primary, secondary, ghost, danger; sizes: sm, md, lg
│   ├── Badge.svelte            # Variants: neutral, discount, target-met, warning, error
│   ├── Input.svelte            # Accessible input with label, error state, prefix/suffix slots
│   ├── Select.svelte           # bits-ui Select wrapper
│   ├── Switch.svelte           # bits-ui Switch wrapper
│   ├── Icon.svelte             # Unified Lucide icon sizing & stroke wrapper
│   └── Spinner.svelte          # Loading indicator
├── molecules/
│   ├── SearchInput.svelte      # Input + Search icon + clear button + debounce support
│   ├── PriceDisplay.svelte     # Formatted price + strikethrough original + Discount Badge
│   ├── ThemeToggle.svelte      # Light / Dark / System switcher
│   ├── LocaleSwitcher.svelte   # Language selector backed by Paraglide
│   ├── EmptyState.svelte       # Icon + title + description + optional CTA Button
│   └── StatCard.svelte         # Metric card for dashboard summary
├── organisms/
│   ├── Navbar.svelte           # Brand, navigation links, ThemeToggle, LocaleSwitcher
│   ├── GameSearchModal.svelte  # bits-ui Dialog + SearchInput + results + target price input
│   ├── WatchlistCard.svelte    # Game capsule, PriceDisplay, target price, toggle, actions
│   ├── EditTargetModal.svelte  # Update target price or clear for "any discount"
│   ├── ChannelFormModal.svelte # Dynamic form for Discord / Telegram / ntfy / Webhook
│   └── AlertLogTable.svelte    # Recent alert history with status badges
└── templates/
    └── AppShell.svelte         # Responsive container, Navbar, toast region, main slot
```

## 3. Color Scheme & Semantic Theme Tokens

All colors must be referenced through semantic CSS custom properties mapped to Tailwind theme variables in `src/app.css`. **Hardcoded hex/rgb values in components are forbidden.**

### Theme Persistence
- `theme` store supports `'light' | 'dark' | 'system'`, persisted in `localStorage`.
- An inline script in `app.html` applies the `dark` class before first paint to eliminate FOUC.

## 4. Internationalization (i18n)

- **Detection Order**:
  1. User-selected override stored in `app_settings` / `localStorage`.
  2. Browser/OS language (`navigator.language`, e.g., `pt-BR`, `pt` -> `pt-BR`).
  3. Fallback: `en`.
- **Zero Hardcoded Strings**: Every visible label, placeholder, aria-label, toast, and error message must come from `m.<key>()` generated by `paraglide-js`.
- **Locale Files**: `frontend/messages/en.json` (source of truth) and `frontend/messages/pt-br.json`.
